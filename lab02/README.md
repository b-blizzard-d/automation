# Лаба 2 — курс валют

### Что делает

Скрипт `currency_exchange_rate.py` спрашивает у сервиса курс одной валюты к другой на нужную дату и сохраняет ответ в JSON в папку `data/`.
Если что-то пошло не так (кривые параметры, API ругается, сервер не отвечает), пишет об этом в консоль и в `error.log`.

### Что поставить

Нужен Python 3 и `requests`:

```bash
cd lab02
pip install -r requirements.txt
```

Сервис должен быть запущен на `http://localhost:8080`.

### Как запускать

```bash
python3 currency_exchange_rate.py <ИЗ> <В> <ГГГГ-ММ-ДД>
```

Примеры:

```bash
python3 currency_exchange_rate.py EUR MDL 2025-01-01
python3 currency_exchange_rate.py UAH MDL 2025-04-11
```

Пять дат одной строкой (каждые 50 дней):

```bash
for d in 2025-01-01 2025-02-20 2025-04-11 2025-05-31 2025-07-20; do python3 currency_exchange_rate.py EUR MDL $d; done
```

Если ничего не задавать, скрипт стучится на `localhost:8080` с ключом `EXAMPLE_API_KEY`. Хочешь другой сервер или ключ, то задай `API_URL` / `API_KEY`:

```bash
API_KEY=EXAMPLE_API_KEY API_URL=http://localhost:8080 python3 currency_exchange_rate.py EUR MDL 2025-01-01
```

Запускать можно из любой папки, `data/` и `error.log` всё равно появятся рядом со скриптом.

### Как устроено

- читаем 3 аргумента из `sys.argv` (если их не 3, то подсказка и выход);
- проверяем валюты (3 латинские буквы, переводим в верхний регистр) и дату (формат ГГГГ-ММ-ДД, от 2025-01-01 до 2025-09-15);
- шлём `POST /?from=..&to=..&date=..` с `key=...` в теле, смотрим на код ответа, JSON и поле `error`;
- если всё ок, кладём ответ сервера как есть в `data/<из>-<в>-<дата>.json`;
- любая ошибка идёт через `bail()`: текст в stderr, строчка в `error.log` (через `log_err()`), выход с кодом 1.

### Что получилось

Прогнала EUR → MDL на 5 дат и ещё UAH → MDL просто попробовать. Сервис отдаёт `rate` = сколько единиц первой валюты дают за 1 единицу второй (то есть для EUR MDL выходит около 0.05, а 1 евро примерно 19.3 лея).

Дата → курс:

- 2025-01-01 → 0.051785029983532356 (1 EUR ≈ 19.3106 MDL)
- 2025-02-20 → 0.05131626212346693 (1 EUR ≈ 19.487 MDL)
- 2025-04-11 → 0.05123607019341617 (1 EUR ≈ 19.5175 MDL)
- 2025-05-31 → 0.051138600950155204 (1 EUR ≈ 19.5547 MDL)
- 2025-07-20 → 0.050632398659254084 (1 EUR ≈ 19.7502 MDL)
- UAH → MDL, 2025-04-11 → 2.349624060150376

Файлы в `data/`:

- `eur-mdl-2025-01-01.json`
- `eur-mdl-2025-02-20.json`
- `eur-mdl-2025-04-11.json`
- `eur-mdl-2025-05-31.json`
- `eur-mdl-2025-07-20.json`
- `uah-mdl-2025-04-11.json`

Например `data/eur-mdl-2025-01-01.json`:

```json
{
  "error": "",
  "data": {
    "from": "EUR",
    "to": "MDL",
    "rate": 0.051785029983532356,
    "date": "2025-01-01"
  }
}
```

