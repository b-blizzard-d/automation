# Репозиторий automation

Этот репозиторий создан в рамках вводного курса по Linux в Государственном университете Молдовы (USM).
Здесь собраны лабораторные работы, посвящённые написанию shell-скриптов для автоматизации задач
администрирования Linux: резервного копирования, обслуживания системы и других рутинных операций.

Каждая лабораторная работа находится в отдельном каталоге и разрабатывалась в отдельной ветке
с тем же названием, после чего была влита в ветку `main`.

## Содержание

- [lab01](lab01/) — скрипт `backup.sh` для создания резервной копии каталога в архиве `tar.gz`
  с датой в имени файла. Подробное описание, примеры запуска и разбор ошибок — в
  [lab01/README.md](lab01/README.md).
- [lab02](lab02/) — скрипт на Python, который берёт курс валют с API и сохраняет в JSON.

## Как пользоваться репозиторием

1. Склонировать репозиторий и перейти в него:

   ```bash
   git clone https://github.com/b-blizzard-d/automation.git
   cd automation
   ```

2. Перейти в каталог нужной лабораторной работы и прочитать её README:

   ```bash
   cd lab01
   cat README.md
   ```

3. Запустить скрипт по инструкции из README, например:

   ```bash
   ./backup.sh ~/documents ~/backups
   ```
